# Benchmark data

Own reviewed benchmark records, source evidence, validation, ingestion, and immutable releases. The benchmark website and API live in rewire-bio/rewire-database. Execution lives in rewire-bio/rewire-benchmarks.

Preserve IDs, numerical values, source evidence and historic release bytes. Changes to scientific records require review and a new release. Never publish private contributor data or automatically publish submissions. Do not add credentials or emulator state. Run tests, type checking and a data build before publishing.
