# Model pages, batch 7, 2026-11-27

Prepared by Claude agents. No human review is claimed. Two research agents fetched sources and wrote the content, one agent verified it, one applied the verifier's findings, and a separate session checked and applied the result.

## What changed

21 Tier 2 model records gain a `profile`, and 19 of them a `run_guide`. The new source records in `batch.jsonl` pin the files the content was written from. No result, evaluation or claim was added or changed, and no existing attribute was edited.

Nine records selected for this batch are not in it. CNN, GCN, CNN-RNN, Transformer, GAT and NeuralFP are generic baselines with no release of their own. GPT-4.1 and Claude Sonnet 4 are closed general-purpose models. Protriever's official repository holds only a README although its paper says the code is released there.

## Sources

From this batch on, the research brief asks for the model paper's full text wherever an open copy exists. 15 of the 21 pages have it. The others rest on an abstract, the repository and the model card: UniRep and UniRep evotuned (the open copy is on bioRxiv, which was rate limiting), AIDO Protein-RAG (bioRxiv only), MIF and MIF-ST (the journal page answers with a robot check), and Prot-T5's journal version (paywalled; the arXiv version was read).

Every fetched file was kept, whatever its licence, and uploaded to the private archive bucket under the sha256 its source record pins. Files whose licence allows redistribution are also in `artifacts/`.

## Structured facts

The content files in `specs/` carry a `structured` list: 29 entries, one per released checkpoint. They are not written to the records in this change.

## How statements were checked

The method is that of batch 1 (`docs/reviews/2026-11-26-model-pages-batch-1.md`). Every copied passage was confirmed present in its saved file by `scripts/enrich/check_spec.py`. A verifier agent that had not written the content judged 622 statements against the saved files and raised 17 findings: 2 contradicted by a source, 10 that went partly beyond it and 5 with no support. All were applied; in one the fixer found the verifier half wrong and kept the supported half. The commonest fault was a code licence stated from a lookup that was never saved; those are now recorded as not stated. No page in this batch was read in full by the applying session before merge.

## Corrections this batch shows are needed in existing records

These are not made here.

- ESCOTT: the record's description says it uses population allele frequencies. The paper puts that step in PRESCOTT and says ESCOTT relies on sequence and structure only. The paper also has an open journal version (Genome Biology 26:113, 2025).
- MULAN: the record calls it a ProteinGym substitution baseline. Its paper does not mention ProteinGym or zero-shot scoring.
- Wavenet: the release is SeqDesign, and its developers do not use the name WaveNet.
- AIDO Protein-RAG: the developer has renamed the models GB.Protein-RAG.

## Run guides

All have status `source_reviewed_not_executed`. None was run. S2F-MSA and S3F-MSA have none: no checkpoint or ensembling code is released.
