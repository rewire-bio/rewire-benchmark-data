The already-cached main-text XML (`workbench/source-review-20261006/PMC6734286.xml`, same SHA-256 already on file, re-used not re-fetched) contains **Table 2 ("Overview of the datasets used during this study")**, which states, quoted/transcribed directly from the table markup:

|---|---|---|---|---|---|

**These are raw per-dataset totals, not a confirmed scored denominator for any individual Figure S10 experiment, and must not be read as one.** This is the same distinction already required of the Baron Human intra-dataset figures elsewhere in this use case's evidence base (Table 2's own "No. of cell populations (**>10 cells**)" column header states a population-level filtering step exists before scoring — populations with 10 or fewer cells are excluded from the stated population count — and the Methods text describes additional per-experiment exclusions, such as restricting scoring to cell populations present in the training data). Whether, and how, an analogous cell-level filtering step changes the actual number of cells scored in each individual Figure S10 train-test experiment is **not stated** in the retrieved main text or supplement. Accordingly: **the scored denominator behind each Figure S10 percentage is unreported in the sources retrieved in this pass.** Table 2's raw per-dataset cell counts (12,832 / 8,758 / 14,636) are recorded here only as the best available upper-bound context, not as the denominator, and should not be multiplied against the percentages above to back-calculate an implied rejected-cell count.

**An unexplained data point, reported as observed and not interpreted:** in the raw Table 2 markup, the AMB row (a different, single-dataset figure used elsewhere in the paper) shows the identical cell/gene counts (12,832 / 42,625) as the VISp row directly below it. **New content located, directly on the previously-unresolved gap** ("CellTypist's exact rejection/'uncertain' threshold mechanism and any independent cross-study validation metric"):

- **Novel/unknown-type-detection mechanism, quoted verbatim** (Methods, "Cell type prediction"): *"Of note, for each cell, we didn't sum up the probabilities to one across cell types to provide a quantification of the confidence score of each cell type, enabling the examination of novel cell types in the test data."* This is a precise, directly on-topic mechanism description that neither prior dossier located: CellTypist's novel-type signal is described here as the **unnormalized per-class sigmoid probability** (not summed to 1, unlike a softmax), rather than any fixed numeric cutoff or calibrated threshold. No specific numeric cutoff value for calling a cell "novel"/unassigned was found in this document. **This is a mechanism description only; no accuracy, precision, recall, or other detection-performance figure for novel/unknown-type identification specifically was located in this document, and none should be inferred from the mechanism description alone.**
- **More precise internal-validation figures than the main text's rounded "~0.9"**, quoted verbatim (Results, "CellTypist performance on the cross-tissue immune reference"): *"the CellTypist models trained from the remaining dataset (90%) demonstrated the precision of 0.96 and 0.9 at the high- and low-hierarchy levels, respectively... The main text separately mentions "two additional studies of the human intestinal tract and lung" as a cross-validation; I searched this document's `pdftotext`-extracted text layer for "intestin," "lung," and "independent stud[y/ies]" and found no match. **This negative result is bounded to the text layer searched**: as established elsewhere in this dossier series, `pdftotext` extraction does not reliably capture text embedded within raster figure panels (axis labels, in-figure annotations), so a reference to gut or lung tissue appearing only inside a figure image, rather than in running text, would not have been found by this search. The cross-study validation metric therefore remains unresolved, not affirmatively absent from the document.

## Bounded-search completion criteria for this use case

Given three successive dated passes (10-06 dossier, early-10-07 follow-up, this pass) have each independently searched, retrieved, cross-checked, and in several cases corrected prior work on the same seven-source evidence base, the following is offered as a defensible standard for when further *source-retrieval* effort on this specific use case should be considered exhausted, pending the structural follow-on (rewire-benchmarks #27) rather than further literature search:

- Every source in the existing evidence matrix (scTab, Abdelaal, Hao/Azimuth, Xu/scANVI, Lotfollahi/scArches, Domínguez Conde/CellTypist, scParadise) has had its full text retrieved, hashed, and quote-checked at least once, and at least one supplementary-material access attempt logged, with outcomes precisely distinguished (retrieved / attempted-and-failed / not-attempted) rather than conflated.
- For each of the two remaining **numeric** blockers with a known, concrete, not-yet-exhausted access route (scParadise `media-2.csv`; Hao et al. 2021's bioRxiv preprint, if a future pass judges the version-drift risk acceptable for that specific question), the route and exact URL are now on file in this document, so a future pass does not need to re-run the discovery search — only the retrieval.
- For each blocker with **no known remaining documented public route** (Figure S9 Panel A's missing digits; CellTypist's Supplementary Text proof-of-work gate, now tried via two independent hosts/CDNs — Europe PMC and NCBI PMC directly, plus Science.org, plus now the bioRxiv mirror for a materially different but overlapping document), further search effort would be disproportionate to the likelihood of a new result, and the gap should be treated as a standing, explicitly-flagged limitation of the public record as currently indexed, not as a task remaining for the next pass to re-attempt via the same routes.
- The compound decision-endpoint question (known-type accuracy **and** unknown-type rejection, **at matched coverage**, **across independent studies**, under **one common protocol**) remains unanswered by any single source in this matrix, as concluded in the 10-06 dossier; this pass's new Figure S10 numbers strengthen the evidence base for Abdelaal's genuine cross-dataset brain comparison specifically. VISp and ALM share GSE115746. MTG is a separate human single-nucleus dataset; combinations involving MTG include cross-species data. Some two-dataset training combinations still share the mouse study with the test dataset, so independent-study holdout must not be inferred for all nine combinations. This does not change that overall conclusion, since Abdelaal 2019 predates scTab/CellTypist/Azimuth/scANVI/scParadise and does not evaluate them. **This use case remains open.** The follow-on measurement gap is already tracked at rewire-benchmarks #27; no further duplicate issue should be opened.

**Bounded research completion is a narrower claim than solving #27, and the two should not be conflated.** A bounded evidence-research pass over a fixed, already-identified source set can reach a defensible stopping point — as this one does, for the Figure S9/S10 re-examination and the CellTypist/scParadise access-route check specifically — without every internal numeric contradiction in those sources being resolved. The Hao et al. 73.8%/79.4% conflict and the scArches Fig. 4c denominator are exactly this kind of standing source-internal limitation: they do not need to be (and must not be) fabricated into a false resolution for this research pass to be considered complete on its own bounded terms. What a bounded pass **cannot** leave undone is disposition of the candidates it did newly surface: each accessible new finding above (Figure S10 Panels A/B; the CellTypist mechanism/metric quotes) needs an explicit recommendation — ingest, do not ingest, or ingest only a named subset, each with a stated reason — rather than being left as an undispositioned finding for an indefinite future pass to pick up. That disposition is given in the next section. Neither this disposition nor anything else in this document resolves, measures, or substitutes for the common-protocol cross-study benchmark tracked at rewire-benchmarks #27; that remains separate, unstarted, follow-on measurement work, not literature search.
