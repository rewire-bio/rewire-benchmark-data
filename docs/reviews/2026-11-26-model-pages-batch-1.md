# Model pages, batch 1, 2026-11-26

Prepared by Claude agents. No human review is claimed. Four research agents fetched sources and wrote the content; a separate session checked and applied it.

## What changed

25 Tier 1 model records gain a `profile`, and 24 of them a `run_guide`. They were chosen by the number of results each holds, among Tier 1 models with no profile, leaving out names that occur on two records and closed general-purpose models. 150 new source records pin the files the content was written from. No result, evaluation or claim was added or changed, and no existing attribute was edited.

## How statements were checked

- Every fact with status `source_checked`, every section, strength, limitation, diagram and run step carries one or more passages copied from a fetched source file. `check_spec.py` confirms each passage occurs in the file, after normalising whitespace, and that each file matches its recorded SHA-256. The passages are kept in `specs/` and are not written to the records.
- Each profile and run guide was parsed with `profileSchema` and `runGuideSchema` before the records were changed.
- One session read three of the 25 (Enformer, DeepVariant, Evo) statement by statement against the passages.
- A passage being present does not prove the statement follows from it. That part rests on the writer and the three read in full.

## Sources

Fetched on 2026-11-26: repository files at a pinned commit, Hugging Face model cards and configuration files at a pinned revision, Hugging Face API responses as served, and open paper pages. A file is kept under `artifacts/` only where its licence allows redistribution; otherwise the record holds its hash and URL. No paywall was passed and no browser User-Agent was set. bioRxiv and Europe PMC refused several full texts; those profiles say so under gaps.

## Run guides

All 24 have status `source_reviewed_not_executed`. None was run.
