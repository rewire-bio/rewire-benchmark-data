# Model pages, batch 2, 2026-11-26

Prepared by Claude agents. No human review is claimed. Four research agents fetched sources and wrote the content; a separate session checked and applied it.

## What changed

25 Tier 1 model records gain a `profile`, and 20 of them a `run_guide`. They are the next Tier 1 models by number of results held, after batch 1, leaving out names that occur on two records, benchmark baselines and closed general-purpose models. 195 new source records pin the files the content was written from; a file already pinned in the store is cited from its existing record. No result, evaluation or claim was added or changed, and no existing attribute was edited.

## How statements were checked

The method is that of batch 1 (`docs/reviews/2026-11-26-model-pages-batch-1.md`): a passage copied from a fetched file for every source-checked fact, section, strength, limitation, diagram and run step, confirmed present by `check_spec.py`; every profile and run guide parsed with the store's schemas; two of the 25 (SpliceAI2, Ladon) read statement by statement against their passages. A passage being present does not prove the statement follows from it.

## Run guides

All have status `source_reviewed_not_executed`. None was run. Five models have no run guide because nothing runnable is published or documented; the reason is in the table.
