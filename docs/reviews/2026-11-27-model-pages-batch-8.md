# Model pages, batch 8, 2026-11-27

Prepared by Claude agents. No human review is claimed. Three research agents fetched sources and wrote the content, two agents verified it, two applied the verifiers' findings, and a separate session checked and applied the result.

## What changed

32 Tier 2 model records gain a `profile`, and 28 of them a `run_guide`. The new source records in `batch.jsonl` pin the files the content was written from. No result, evaluation or claim was added or changed, and no existing attribute was edited.

With this batch every Tier 2 model has a page except those listed here. Six generic baselines (CNN, GCN, CNN-RNN, Transformer, GAT, NeuralFP) have no release of their own. GPT-4.1 and Claude Sonnet 4 are closed general-purpose models. Protriever's repository holds only a README. FrameFlow was researched and is left out: a safety classifier interrupted the agent applying review findings to it, and the page was not taken further. Names that sit on two records are also still without a page.

## How statements were checked

Every copied passage was confirmed present in its saved file by `scripts/enrich/check_spec.py`. Two verifier agents that had not written the content judged 1049 statements across the batch's 33 researched pages and raised 82 findings (7.5%), the highest rate of any model batch: 6 contradicted by a source, 70 that went partly beyond it and 6 with no support. All were applied except one, a release month that cannot be entered as a date. The counts in this document's table are for the 32 pages that are in the batch (79 findings).

Two causes account for most of the rise.

- Eleven records are the Bacformer family: one paper, one repository, one model card per checkpoint. One unsupported sentence, that the weights file is larger than the stated size because it includes a classification head, was written on nine pages, and several pages carried a fact from a sibling checkpoint's card. The agents applying findings were told to correct these patterns on every page, not only where a verifier flagged them: 23 further corrections.
- Specifics no saved file prints: checkpoint file names for MochiBind, an HTTP status and date for two unreadable Bacformer checkpoints, inferred weights licences on VespaG, GeoDock and Graphinity (now recorded as not stated).

A family with shared sources needs a different procedure: the common facts written and verified once, and each checkpoint page adding only what its own card states. That is not yet in the brief.

No page in this batch was read in full by the applying session before merge.

## Things a reader of these records should know

- Graphinity: all eight released checkpoints were trained on FoldX-generated values. The authors present their 0.87 correlation as evidence of overtraining.
- GeoDock: the paper's abstract says it falls behind conventional methods and AlphaFold-Multimer on the antibody-antigen benchmark.
- OpenFold3: the default checkpoint is not in the saved file listing, so its weights address, gating and licence are not stated; the developers' documents disagree on which parameter set is the default.
- RFD4-Proteina: the model card's checkpoint sizes contradict the developers' release manifest. The page gives the manifest's figures.
- Two Bacformer checkpoints (protein-family modelling and essential genes) could not be read without an account.
- MPNN: the only release by the architecture's authors holds a model class and unit tests. Whether this record is a model or a baseline architecture is open.
- ESM-C: the organisation that publishes it has been renamed, and the December 2024 weights the record's results came from now only point at the new repositories.
