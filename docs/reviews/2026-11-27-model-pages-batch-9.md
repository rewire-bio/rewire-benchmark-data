# Model pages, batch 9, 2026-11-27

Prepared by Claude agents. No human review is claimed. Three research agents fetched sources and wrote the content, two agents verified it, two applied the verifiers' findings, and a separate session checked and applied the result.

## What changed

50 Tier 3 model records gain a `profile`, and 44 of them a `run_guide`. They are the biology-specific Tier 3 models: single-cell and cell biology, mass spectrometry and small molecules, molecular interactions, and microbial classification. The new source records in `batch.jsonl` pin the files the content was written from. No result, evaluation or claim was added or changed, and no existing attribute was edited.

## Records selected and not in this batch

- LLF, MFE and DeepGraphDTA are rows in a benchmark's table with no paper, repository or model card of their own. LCDD-team is a CASP16 prediction group. These are probably not models and their records should be retyped.
- "Cellpose + easy 100%" is a fine-tuning condition of one study.
- "Cellpose baseline": its record has status `excluded`, so it is not published and takes no page.
- Emb-Cos and the MassSpecGym DeepSets fingerprint predictor are baselines built inside a benchmark, with code and no named weights. The verifier confirmed that the saved files do not support treating either as a released model.
- PGraphDTA: the agent applying review findings was interrupted while editing it, and the page was not taken further. Its saved paper was never read as text, so the unedited page understates what the paper gives.
- 36 general-purpose language models (Claude, GPT, Gemini, Llama, Qwen and others) that a benchmark prompted. Whether and how they get a page is an open decision.

## How statements were checked

Every copied passage was confirmed present in its saved file by `scripts/enrich/check_spec.py`. Two verifier agents that had not written the content judged 1,549 statements on the 54 researched pages and raised 43 findings (2.8%): 9 contradicted by a source, 29 that went partly beyond it and 5 with no support. The table below covers the 50 pages in the batch (1451 statements, 36 findings). All were applied, with further corrections where the same fault recurred.

Two things differ from earlier batches.

- Several faults were understatements: a fact marked unreported, or a discrepancy called unexplained, when the saved paper states or explains it (a code licence for scELMo, the training set for UCE, a parameter count for MetageNN, the training-cell figures for Stack). The verifiers searched every saved text for such facts.
- Four pages said a site had been searched or an address did not resolve with no saved response behind the claim. Those statements were removed or reduced to what the saved files show. Six more said no Hugging Face repository "was found"; they now say none is named in the sources read.

Two rules were applied across the batch for consistency. `gated` is null when no saved file gives any location for the weights, and false only when a saved file gives a location that downloads without an account. A weights licence is recorded only when a saved file states one for the weights; a repository's code licence is not carried over to weight files that sit in it.

No page in this batch was read in full by the applying session before merge.

## Things a reader of these records should know

- FRIGID: its developers superseded their earlier results because test-set information had reached the training of a component (MassSpecGym top-1 fell from 18.29% to 9.05%). The benchmark source for this record still lists 18.29%.
- DiffMS: the benchmark that ran it reports a padding bug and a checkpoint it could not reproduce.
- MIST and 3DMolMS: the released code and weights differ from what the papers describe.
- MassFormer: only a demonstration checkpoint is public.
- MolForge: its badge, README text and licence file name three different licences.
- GraphDTA: the paper says pretrained models are in the repository; the repository's file listing holds none.
- PLM-GraphDTA: the training script selects its checkpoint on training loss.
- PerturbPFN: nothing is released, neither code nor weights.
- ProtCell: the repository matches the abstract's figures, and no saved file ties it to the paper's authors.
- Stack: 189 million cells passed quality control, 149 million are the training split, and the README says about 150 million.
- scRM: the README's direct training command writes a run that the reproduction guide lists under a different seed; the saved files do not settle which the command produces.
- Seven single-cell pages rest on a paper's abstract and the repository, because the paper is on bioRxiv or not open access: CellPLM, scGPT-spatial, Novae, Tahoe-x1, TranscriptFormer, scBERT and ProtCell.
