# Model pages, batch 5, 2026-11-26

Prepared by Claude agents. No human review is claimed. Four research agents fetched sources and wrote the content, one agent verified it, one applied the verifier's findings, and a separate session checked and applied the result.

## What changed

21 Tier 2 protein model records gain a `profile`, and 20 of them a `run_guide`. The new source records in `batch.jsonl` pin the files the content was written from. No result, evaluation or claim was added or changed, and no existing attribute was edited.

Four records selected for this batch are not in it. ProtSSN and xTrimoPGLM were not finished by their research agent and will be rerun. CNN and GCN are generic baselines, not released models, and need a different kind of page.

## Structured facts

The content files in `specs/` carry a `structured` list: 67 entries, one per released checkpoint, with parameter count and context length as numbers, licences as identifiers, code and weights addresses, gating and a release date, each backed by a copied passage. They are not written to the records in this change.

## How statements were checked

The method is that of batch 1 (`docs/reviews/2026-11-26-model-pages-batch-1.md`). Every copied passage was confirmed present in its saved file by `scripts/enrich/check_spec.py`. A verifier agent that had not written the content then judged 639 statements against the saved files and raised 34 findings: 30 statements that went partly beyond their source and 4 with no support, none contradicted by a source. The most common finding was a remark about how a benchmark lists the model, which the model's own sources do not show. Each finding was applied by rewording or removing the statement, and the checker was run again. No page in this batch was read in full by the applying session before merge.
