# Model pages, batch 3, 2026-11-26

Prepared by Claude agents. No human review is claimed. Four research agents fetched sources and wrote the content; a separate session checked and applied it.

## What changed

24 Tier 1 model records gain a `profile`, and 22 of them a `run_guide`. 160 new source records pin the files the content was written from; a file already pinned in the store is cited from its existing record. No result, evaluation or claim was added or changed, and no existing attribute was edited.

`lit-microbial-20261011-virobench-model-virodnabert2` was in this batch and is not changed: its sources were fetched but its page was not written. It needs a rerun.

`docs/model-pages.md` is the brief the research agents work from, committed so that later batches do not depend on a session's scratch folder.

## How statements were checked

The method is that of batch 1 (`docs/reviews/2026-11-26-model-pages-batch-1.md`): a passage copied from a fetched file for every source-checked fact, section, strength, limitation, diagram and run step, confirmed present by `check_spec.py`; every profile and run guide parsed with the store's schemas. A passage being present does not prove the statement follows from it. No page in this batch was read in full by the applying session before merge; five are compared with their live pages afterwards.

## Run guides

All have status `source_reviewed_not_executed`. None was run. Where a step adds a line the sources do not give (a clone, a download, a file written for input), its explanation says so. No run guide: optimus-5-prime, hgt5.
