# Evidence reviews

Dated records of how stored values and claims were sourced and checked: search logs, source retrievals, value-by-value verification, scope decisions and known gaps. Each review describes the repository as it was on its date. They are not edited after merge; a later review supersedes an earlier one.

- `use-cases/`: one dossier per use-case evidence pass, plus the use-case coverage audits.
- Top level: catalogue-wide reviews of models, benchmarks, extractions and profiles, named `<date>-<topic>`.

New reviews follow [the collection procedure](../collection.md#5-review).
