# Model pages, batch 4, 2026-11-26

Prepared by Claude agents. No human review is claimed. Three research agents fetched sources and wrote the content; a separate session checked and applied it.

## What changed

15 Tier 1 model records gain a `profile`, and 14 of them a `run_guide`. 98 new source records pin the files the content was written from. No result, evaluation or claim was added or changed, and no existing attribute was edited. With this batch every Tier 1 model has a profile except ViroDNABERT2 (to be rerun), records whose name occurs twice, benchmark baselines and closed general-purpose models.

## Structured facts

The content files in `specs/` also carry a `structured` list: 28 entries, one per released checkpoint, with parameter count and context length as numbers, licences as identifiers, code and weights addresses, gating and a release date, each backed by a copied passage. They are not written to the records in this change. They are kept so that a later change can load them as queryable values.

## How statements were checked

The method is that of batch 1 (`docs/reviews/2026-11-26-model-pages-batch-1.md`). A passage being present does not prove the statement follows from it. No page in this batch was read in full by the applying session before merge.

## Run guides

All have status `source_reviewed_not_executed`. None was run. The three hEvo records keep a run guide although their weights are gated for peer reviewers; each guide says so in its prerequisites. No run guide: jores-plant-promoter-cnn.
