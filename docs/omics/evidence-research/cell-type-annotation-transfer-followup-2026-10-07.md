## Focus 1 — scArches Fig. 4c "~84%" denominator: **unresolved**; a code-grounded candidate explanation exists, not a proof

The main-text quote (same XML already on file): *"scArches achieved ~84% accuracy across all tissues (Fig. 4c)."* Fig. 4's own legend, quoted in full for the first time here: panel **(c)** is *"Location of misclassified and unknown cells after transferring labels from the reference to the query data. The highlighted tissue represents tracheal cells, which we removed from the reference data,"* and panel **(e)** is *"Numbers of correct, incorrect and unknown cells across different tissues."* **Fig. 4c is a spatial/location plot, not a bar chart or table — the quantitative breakdown that could substantiate "~84%" is Fig. 4e's content, not 4c's.** This citation/content mismatch is a confirmed fact, independent of the rest of this section.

Per the paper's own Code/Data availability statement, I fetched `github.com/theislab/scarches-reproducibility` (public, pinned to HEAD commit `445d7dce80bb7ae1102e7bccd80ce193ecd64008`, `pushed_at` 2021-05-12T10:29:07Z). The first two contained no matching code. `tabula_senis_muris.ipynb` (SHA-256 `f81ab43d6778df468490b6fdbda619ab96a5d64e26c560e51b67a7b0f9bfe2b4`, 5,653,988 bytes, GitHub blob `697b2925c8d8cff34c4ecc0281c3963e39ef29e7` at the pinned commit) contains a weighted-kNN classification (`n_neighbors=20, threshold=0.5, pred_unknown=True`) over this exact experiment (`cell_type_key = 'cell_ontology_class'`, trachea excluded from the reference in cell 8).

**Artifact-level observations (not source-printed, read directly from this notebook's saved cell outputs, not re-executed by me):** the notebook sums per-tissue Correct/Incorrect/Unknown counts separately for Trachea vs. all other tissues. These two sums (9,330 and 90,120) **numerically match** the paper's independently stated trachea-cluster size ("n = 9,330") and total query size ("90,120 cells from 24 tissues"). That correspondence is notable and worth recording, but **it is not, by itself, proof that this specific notebook execution produced the numbers behind the published Fig. 4c/4e** — the paper does not state that this notebook, at this commit, is the exact run behind the figure, and I found no explicit author statement linking the two. ## Focus 3 — Hao et al. 2021's 73.8% vs. 79.4% conflict: not a population difference; conflict retained

Figure 7/S7D legend: *"For all 17,480 (32.9%) of query cells where Seurat and scArches returned different annotations based on the transcriptome, we calculated protein-based classification metrics... In 73.8% of cases, we observe stronger support for the Seurat annotation."* STAR★Methods: *"For the remaining 17,480 query cells, the two methods returned two divergent annotations... In 79.4% of cases, we observe stronger support for the Seurat annotation (Figure S7E)."*

Both passages state the identical denominator population — "17,480 (32.9%)" / "the remaining 17,480 query cells" — the same discordant-annotation subset of the same query dataset. **This directly rules out "distinct populations" as the explanation; it is not merely unsupported, it contradicts the text.** What remains undetermined: whether the Methods' specific Pearson-correlation-centroid procedure is the same computation as the unspecified "protein-based classification metrics" behind panel D, or a different metric on the same 17,480 cells; and whether "(Figure S7E)" in the Methods is a mislabeled citation (panel E is elsewhere captioned as a computing-time panel, not a protein-support panel). I attempted to retrieve the actual Figure S7 image to settle this: a guessed Elsevier CDN URL (`ars.els-cdn.com/.../mmc1.pdf`) returned HTTP 404 (2026-10-07T01:00:30Z); the NCBI PMC article page lists only three `.xlsx` data-table supplements (`mmc1`–`mmc3`), not a supplementary-figures PDF (2026-10-07T01:00:31Z).
